# 犯罪故事分镜

使用项目中的 `gen_story.py`、`QwenImage21Pipeline` 与三张现有角色肖像生成。每帧只使用对应角色的一张肖像作为参考，完整英文提示词见 [prompts.json](prompts.json)。

## 匿名来信 · 敲诈

林伟在雨夜收到匿名勒索消息。对方留下的牛皮纸信封令威胁变得具体。惊慌过后，他在清晨保存手机与信封，准备向警方报案。

## 消失的怀表 · 盗窃

赵敏在闭馆时发现古董怀表不翼而飞，展柜中只剩空荡的红绒盒。她循着展柜边缘的细小线索，在储物室的抽屉里找回了怀表。

![赵敏发现空展柜](theft/01_empty_case.png)

![赵敏找回怀表](theft/02_found_watch.png)

## 雨夜的碰撞 · 交通事故

陈浩的车在雨夜撞上路边护栏。他停在现场记录损坏情况，天亮后整理照片与经过，准备报告事故。

![陈浩站在事故现场](collision/01_impact.png)
