# 犯罪故事连环画

三组故事，每组四格。画面由项目中的 `gen_story.py` 调用 Qwen-Image-2.1 生成；每格仅传入对应角色的一张肖像作为人物参考。完整英文提示词与中文分镜文案见 [prompts.json](prompts.json)。前一版双格故事仍保存在 `../crime_stories/`。

四格拼页：[匿名来信](extortion/comic_sheet.png) · [消失的怀表](theft/comic_sheet.png) · [雨夜逃离](collision/comic_sheet.png)

## 1. 匿名来信 · 林伟

雨夜，林伟收到以曝光隐私为要挟的匿名信息。门外无人的走廊里，一只信封静静躺在门槛上；里面是从窗外偷拍的自家照片。惊恐过后，他在天亮前整理手机信息与信封，决定求助。

**① 陌生信息。** 指尖悬在手机上方，林伟的目光突然定住。

![林伟收到匿名勒索信息](extortion/01_message.png)

**② 门口的信封。** 他扶住门框，伸手去取没有署名的信封。

![林伟在门口捡起信封](extortion/02_envelope.png)

**③ 被监视的证据。** 照片里的窗户正是他的家；他下意识捂住嘴。

![林伟看到偷拍照片](extortion/03_proof.png)

**④ 天亮前的决定。** 他保存信息和信封，开始整理证据。

![林伟整理证据](extortion/04_decision.png)

## 2. 消失的怀表 · 赵敏

闭馆后，赵敏发现展柜里的银怀表失踪。她从锁扣上的红绒线找到线索，走进储物室，在抽屉的内衬下面找回怀表。

**① 空展柜。** 她停在展柜前，看到红绒垫上只剩圆形压痕。

![赵敏发现怀表失踪](theft/01_discovery.png)

**② 锁扣上的线索。** 她蹲下，用手电照亮一缕细小的红线。

![赵敏检查展柜锁扣](theft/02_trace.png)

**③ 储物室。** 抽屉内衬有破口，她意识到怀表可能藏在下面。

![赵敏搜查储物室](theft/03_search.png)

**④ 找回怀表。** 她掀开红绒内衬，终于看到银色表壳。

![赵敏找回怀表](theft/04_recovery_v2.png)

## 3. 雨夜逃离 · 陈浩

陈浩的车在雨夜撞倒路边无人停放的红色电动车。现场没有其他人，他查看损坏，犹豫片刻，最终重新驾车离开。

**① 碰撞。** 车头与电动车撞在一起，他惊得紧握方向盘。

![陈浩的车撞倒电动车](collision/01_impact.png)

**② 下车查看。** 他扶着额头，看到两辆车都受了损。

![陈浩检查事故现场](collision/02_aftermath_v2.png)

**③ 犹豫。** 他握住车门，又回头看了一眼倒地的电动车。

![陈浩犹豫是否离开](collision/03_choice_v3.png)

**④ 驾车逃离。** 他最终驶离现场，电动车留在雨里。

![陈浩驾车逃离现场](collision/04_escape_v2.png)
